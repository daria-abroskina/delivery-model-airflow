# Batch-scoring

Получение прогнозов времени доставки заказа с помощью ml-модели сразу для большого объема данных один раз в определенный интервал (раз в час, день, месяц и пр.), а не обработки отдельного запроса в режиме реального времени

Для имитации входящих данных используется csv-файл, находящийся по пути  data/input/data.csv

## 🛠️ Установка и запуск

1. Нужно в командной строке перейти в папку с проектом и выполнить:
```docker build -t my_airflow_image .```
 Этой командой соберем образ my_airflow_image на основе образа apache/airflow:3.1.6-python3.12 с установкой в python нужных нам библиотек. 

Затем для запуска Airflow:
```docker-compose up -d```

Airflow будет доступен по адресу http://localhost:8080
Пароль и логин по умолчанию airflow

2. В UI Airflow перейти Admin -> Connections -> Add Connection ->
- Connection ID: my_postgres-db-conn
- Connection Type: Postgres
- Host: my-postgres-db
- Login: my_user
- Password: my_password
- Port: 5432
- Database: my_forecast_db

Это делается один раз, только при самомо первом запуске контейнеров. Даже если контейнеры упадут, заново устанавливать подключение не потребуется.

3. Выполняем первый DAG create_table. Создастся таблица model_predictions в базе данных my_forecast_db. Благодаря вольюмам, в случае падения контейнеров записи в БД сохранятся и будут доступны сразу после поднятия контейнеров. Посмотреть записи в БД можно, выполнив команды:

```docker exec -it my_postges_db psql -U my_user -d my_forecast_db``` 

-> попадаем в командную строку psql и в ней выполняем:
```\dt``` -> Увидим список всех таблиц в БД my_forecast_db

И если таблица model_predictions существует, к ней можно писать обычные запросы, например:
```SELECT * FROM model_predictions LIMIT 10;```

4. Выполняем DAG prediction-dag. После него сформируется таблица в базе данных со значениями признаков, предсказаниями, списком колонок, в которых был выявлен data drift, датой создания записи, а также предупреждением, что предсказание не надежно, если в данных обнаруживается data drift. Реализация сдвига данных выполнена мной в ученических целях для знакомства с Evidently AI и далека от идеала.
